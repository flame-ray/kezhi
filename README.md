# 课织（Kezhi）

课织是一个面向 Windows 10/11 与 Android 的本地优先大学课表应用。当前 0.4.0 版本加入通用选课助手和完整成绩中心：可在用户登录后学习任意学校同域页面的表单、入口与网络资源，生成只读监控候选；支持多课程余量监控、限频退避和官方页面确认。成绩中心支持手动录入、中文 CSV 导入、学期筛选，以及平均分、GPA、学分、通过率和成绩分布统计。应用同时包含周课表、可惯性滑动并自动吸附的日期条、“今天”日程、ICS 导入导出、逐级返回、校历调整、单双周、多套作息、系统提醒与 SQLite 本地持久化。

首次启动默认是空课表，不附带任何虚构课程、学生或学校信息。用户完成教务导入或手动添加课程后才会创建课表数据。

## 本地运行

### Windows 一键启动

直接双击项目根目录的 [`启动课织.cmd`](./启动课织.cmd)。如果已经生成 `src-tauri/target/release/kezhi.exe`，脚本会立即启动原生版；否则会使用 Bun 进入 Tauri 开发模式并自动完成首次编译。

仓库当前已经生成可运行的 Release EXE 和未签名安装包；公开代码签名仍属于后续工作。

无需开发环境的安装程序可从 [GitHub Releases](https://github.com/flame-ray/kezhi/releases) 下载。当前安装包尚未配置公开代码签名证书，Windows 可能显示“未知发布者”。

### Android 开发版

项目已生成 Tauri Android 原生工程，支持 Android 7.0（API 24）及以上版本。Android Studio、SDK 35/36、NDK r28 和 Rust Android targets 配置完成后，可双击 `启动课织安卓版.cmd`；脚本会检测已连接的真机/模拟器，并启动 Android 调试版。

也可以使用命令：

```bash
bun run android:init
bun run android:dev
bun run android:build
```

Windows 上 Tauri 打包需要创建符号链接，因此必须在“设置 → 系统 → 开发者选项”中由用户明确开启开发人员模式。账号、课程和作息只保存在 Android 应用私有 SQLite 中；宁德师范学院已支持应用内官方网页登录，登录后点击顶部“登录完成，导入课表”即可读取课表，密码不会保存。

### 开发模式

```bash
bun install
bun run dev
```

启动 Windows 桌面壳：

```bash
bun run tauri dev
```

如果 npm 依赖源暂时不可用，可以使用本机 Bun 对 React/TSX 源码进行独立构建验证：
- [x] Material 风格竖屏重排、五项底部导航与横排课程文字优化

```bash
bun build src/main.tsx --outdir dist-bun --target browser
```

- 学号、姓名和课程数据默认只保存在本机。

- [x] Android 侧滑和返回键按弹窗、向导步骤、详情页逐级返回，主界面不误退出
- [x] “今天”日程、逐日滑动、课程进行状态与返回周课表
- [x] 课程卡片自动显示单周 / 双周，不依赖手动备注
- [x] 通用选课页面学习器：表单、链接和同域网络资源候选识别
- [x] 多课程余量监控、最短 30 秒限频、失败退避与官方确认
- [x] 成绩录入、中文 CSV 导入、学期筛选和本地编辑
- [x] 加权平均分、GPA、已获学分、通过率和成绩分布
- [x] 大一校历独立适配：2026-09-17 周四作为第 1 周正式上课日，教务全校周次自动换算
- 学校登录与解析通过适配器接入，课表界面只消费统一数据模型。

- 插件能力采用声明权限和最小授权模型。

## 登录隐私边界

- 学号和密码只填写在学校官方 `jwgl.ndnu.edu.cn` 页面，课织不提供密码输入框。
- 原生层固定校验 HTTPS 域名，不接受前端传入任意网址。
- Cookie 值只在 Rust 原生层用于本次学校请求，不返回 React 界面、不写入日志。
- 正方接口响应中的学生资料块会被丢弃，仅课程行进入本地解析器。
- 不提供云同步，课程和账号备注仅保存在当前设备。
- Windows 原生版使用 `%APPDATA%\app.kezhi.desktop\kezhi.sqlite3`，Android 使用应用私有数据库；SQLite 保存失败时会回退到兼容存储并提示用户。

## 同步行为

首次真实导入会保存所选学年和学期。应用启动时，如果距离上次同步已经超过 15 分钟，会尝试在后台恢复该账号会话；应用保持前台运行时每 30 分钟检查一次。新增、删除、教室、教师、节次和周次变化都会进入确认窗口，本地手动课程不会被学校同步删除。

## 课程提醒

设置页可开启系统课程通知并选择默认提前时间；课程详情可快速开关，课程编辑页可设置单独提前时间。课织会依据学期首周日期、课程周次和当前作息方案预定未来 128 条通知，并在相关数据变化或应用再次启动时自动补充。提醒设置随 SQLite 与 JSON 备份保存，ICS 导出会写入 `VALARM`。
