# 课织全功能体检（0.4.3）

体检日期：2026-09-08

本轮没有登录学校账号，也没有向任何学校服务器发送课表、余量或选课请求。结论来自源码审查、纯函数回归测试、Rust 单元测试、生产构建和安装包检查。

## 已接通的功能

- 首次启动为空课表；支持手动添加、长按空格添加、编辑、删除和拖动课程。
- 周一至周日完整周课表、每日日期、1–30 周切换、单周/双周标识、亮色/暗色主题。
- “今天”页日期横向滚动、逐日滑动、课程进行状态和返回周课表。
- 年级推断、宁德师院已知校历、大一非周一开学、首周周一与正式上课日手动调整。
- 多套作息、逐节时间修改、新增后续节次（最多 30 节）。
- 宁德师院正方课表导入、通用 HTTPS 教务页面学习入口、同步差异逐项确认。
- ICS 导入/导出、CSV、JSON 备份恢复、SVG、打印/PDF。
- 本地成绩录入、CSV 导入、筛选、加权平均分、GPA、学分、通过率和分布。
- Windows/Android 系统课程提醒，全局默认与单课程覆盖。
- Windows Credential Manager / Android Keystore 密码保存及官方登录页自动填充。
- 定时选课提醒、只读余量监控、自动提交执行器、验证码/登录失效停止、请求上限与退避。
- Android 系统返回手势按弹窗、向导、详情和二级页面逐级返回；Windows 一键启动。

## 本轮修复与优化

- 缺少或损坏的校历日期不再固定回落到 2026-09-14，而是按所选学年、学期、学校和年级重新建议。
- 自定义周次范围不会再产生第 0 周或第 31 周以上的非法数据；第 25–30 周现在可以正常访问。
- 课程拖到末节时自动保持完整时长并限制在当前作息范围内。
- 系统手势取消周课表滑动时回弹，不再把取消动作误判为翻周。
- 作息时间写入前校验，支持安全添加下一节；SQLite 同步执行相同约束。
- ICS 日期严格校验；旧备份保留缺省校历语义，并拦截重复 ID、断裂节次和逆序时间。
- SQLite 失败后兼容存储也不可用时明确提示导出备份，避免静默丢失。
- 自动选课失败消息优先于矛盾的成功标志，候选课公平轮转，GET 参数不再丢失。
- 立即试跑明确标注会真实提交且不再持久部署；任务完成或停止后自动解除部署，避免重启重复运行。
- 移除渲染线程最后 40ms 的忙等，避免选课页必然丢帧。

## 尚未完成或仍需真实环境验证

- 通用学校入口可以学习同域页面，但目前只有宁德师院正方课表接口经过针对性实现；不能宣称“每所学校都能自动识别”。
- 自动选课原生层仍需把提交地址与一次受信学习记录强绑定；当前主要依赖同域 HTTPS、路径拦截和前端学习结果。
- 学习器尚未完整重放 FormData、URLSearchParams、自定义 CSRF 头等请求形态；复杂学校页面可能需要适配器。
- 点击停止不能撤回已经发出的在途请求；提交 Referer 仍是登录页，不是实际学习页。
- 标准 HTTP Date 通常只有秒级精度，不能保证真正的毫秒级学校时钟校准。
- Android 后台自动同步、正式发行签名/AAB、账号退出与会话清理、插件宿主尚未完成。
- 没有独立“考试安排”模块；当前成绩中心只管理成绩记录。
- 仍需用真实学生会话完成宁德师院端到端导入与选课兼容验收。
- 本轮尝试启动 computer-use 做像素级 UI 验收，但 Windows 沙箱辅助进程连续退出；因此动画与视觉仍需真机人工复测。
