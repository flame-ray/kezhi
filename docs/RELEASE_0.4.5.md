# 0.4.5：弹性导航、翻周误触修复、手机日历

## 本轮实现

- 手机底栏采用一个共享选中滑块，移动过程中轻微拉伸、压缩和回弹。快速切换从当前动画位置接续；减少动态效果模式直接定位。
- 长按取消距离从 12px 调整到 6px，早于翻周的 8px 接管阈值。按下期间捕获全局移动、抬起、取消、滚动、窗口失焦和第二根手指事件，指针捕获转移时也清理计时器。静止按住约 0.8 秒仍可添加课程。
- 设置新增「导入手机日历」入口，进入导出面板。Android 中先确认，再请求系统日历读写权限并写入独立 LOCAL 类型的「课织课表」日历，不使用云端服务。
- 按实际开学日、单双周、课程节次和当前作息展开整学期，每次课程独立为一条日程，时间固定为 Asia/Shanghai；提醒跟随课织设置。
- 同一学期、同一课程 ID 和周次使用稳定标识，再次导入更新已有记录；修改开学日期不会改变标识。仅操作本应用日历中由本应用写入的事件。
- 后台线程以每批 80 条课程提交，避免阻塞 UI。拒绝权限有明确说明，失败显示已完成数量，可重新导入。原有自动选课代码未改动。

## 使用

设置 → 导入手机日历 → 导入手机日历 → 确认写入日历 → 允许日历权限。
然后在手机日历的日历列表中勾选「课织课表」。不同厂商入口名称可能不同。

这是手动写入，不是自动双向同步。课程变动后需再导入；课织内移除的课程不会自动从系统日历删除。若系统日历与课织通知同时开启，可能收到两份提醒，可自行关闭其中一方。
桌面和浏览器保留 ICS 导出，不假装支持 Android 原生日历写入。

## 验证

- 108 项单元测试通过，包含新增 7 项手机日历日期/重复/提醒/时间合法性测试。
- 16 项主流程 UI 检查、9 项原有动效检查、10 项新增手势/日历检查通过，共 35 项。
- 新用例覆盖移动 8px 后停留、移走再移回、取消触摸后停留、随后正常长按、底栏运动中状态/结束对齐/快速切换/减少动态效果，以及模拟 Android 确认、参数、权限失败重试。
- TypeScript、Vite 与 Android Rust/Kotlin 编译通过。浏览器测试仅访问 localhost；原生日历调用使用模拟返回，没有向真实手机写入测试日程。
- 尚未在真机验证各厂商 CalendarProvider、系统权限对话框和日历显示效果；浏览器结果不代表真机 60/120Hz 性能保证。
