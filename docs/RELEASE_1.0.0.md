# 课织 1.0.0

将原计划 0.4.6 的恢复与日历管理更新并入 1.0.0。支持 Android 7.0+（ARM64）及 Windows 10/11（x64）。本说明不代表已完成所有高校和所有手机的兼容性认证。

## 主要更新

- 调课记录中心：设置中集中查看、筛选、修改和撤销单次调课／停课；显示校历变化后未生效的记录，撤销前单独确认。
- 手机日历更新预览：列出新增、修改、删除与不变事件，确认前不写入。支持停课或删课后的事件清理，空课表也可预览。
- 日历隔离保护：仅更新课织本地日历中本应用创建的事件，新事件按账号／学期隔离。旧版事件默认保留；单独勾选清理时，预览会包含可能来自其他账号／学期的旧版事件。
- 预览是一次性、10 分钟有效的本地计划；系统日历变化时要求重新预览。大量更新采用小批事务，部分失败会报告完成数量，需要重新预览后继续。
- 导入前自动备份：确认教务、ICS 或 JSON 导入前保存最近一个恢复点，包含原课程、校历、作息与单次变更。恢复前再次保存当前课表，支持回退恢复操作。
- 备份与课表一起保存到本机数据库；不保存密码或选课提交配置。恢复不覆盖当前成绩、选课助手和凭据。导出备份可由用户自行妥善保管。
- 设置增加联系开发者：邮箱 `rayflame1949@outlook.com`、QQ `3886269343`，支持一键复制及复制失败提示。

## 一并包含的更新

- 导入周次逐条核对，不再把未知周次默认为 1–20 周；保留已知单双周条件。
- Android 课表浏览器增加返回、前进、刷新／停止／重试、修改网址、加载进度，导入按钮位于底部。
- 单次调课／停课、持久化撤销、时间冲突确认，与周课表、今天、提醒和导出联动。
- 长按箭头调节节次，降低翻周误触；非本周课程淡色保留；重叠课程合并入口，不删除原数据。
- 保留现有本地账号密码保存、自动选课、成绩管理、单双周、多套作息、亮暗主题及弹窗动画。

## 升级与限制

- 安装前建议导出一份 JSON 备份。应用私有数据随卸载删除；自动恢复点也在本机，不能替代卸载前的外部备份。账号密码不包含在课表备份中。
- Android 1.0.0 启用独立正式签名，与旧测试签名不同，不能直接覆盖旧版。请先导出外部 JSON 备份，再卸载旧版、安装新版并恢复课表；账号密码需要重新保存，选课提交配置等不在课表备份中。以后正式版将沿用新密钥。详见 [签名与迁移说明](https://github.com/flame-ray/kezhi/blob/v1.0.0/docs/ANDROID_RELEASE_SIGNING.md)。
- Windows 安装程序尚无 Authenticode 公共代码签名，系统可能提示未知发布者。
- 通用课表解析主要支持 HTML 表格，不保证所有高校、图片课表、跨域框架或自绘页面均可导入。HTTP 老教务系统不受支持。
- 旧版手机日历事件没有账号／学期标识，因此默认不自动删除，首次更新可能与旧事件并存；清理前请逐项核对预览。
- 日历删除后若需恢复，可撤销课织里的停课／删除操作或恢复课表备份，再次预览导入；没有系统日历删除回收站功能。
- 正式版本号不意味着所有最初设想都已实现：桌面小组件、独立考试中心和应用内升级仍未纳入本版。
