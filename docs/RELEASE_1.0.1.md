# 课织 1.0.1

1.0.1 是 1.0 正式版的界面与默认行为修正，支持 Android 7.0+（ARM64）及 Windows 10/11（x64）。

## 更新内容

- 教务导入向导默认网址改为空白，不再预设宁德师范学院或任何其他学校；继续按钮会保持禁用，直到用户输入有效的 HTTPS 教务系统网址。
- 未填写网址时，内部校历建议也使用通用学校状态，不再提前套用宁德师院的开学日期。
- 已有宁德师院适配器仍然保留，仅在用户主动填写相应官方网址时启用。
- “联系开发者”移动到设置页顶部，增加图标、主题色边框和柔和强调背景，在手机上无需滚动即可看到。
- 联系方式保持为邮箱 `rayflame1949@outlook.com`、QQ `3886269343`，支持一键复制与复制失败提示。

## 验证情况

- 152 项前端单元测试通过。
- 教务导入界面检查通过：验证首次打开网址为空、空网址无法继续、通用网址不会识别成宁德师院，以及登录、读取和周次确认流程不受影响。
- 设置界面检查通过：验证联系开发者位于第一项、联系方式复制正确，以及调课记录和导入备份流程不受影响。

## 升级说明

- 从 1.0.0 正式版升级：使用同一把正式签名，可以直接覆盖安装，应用本地数据会保留。升级前仍建议导出 JSON 备份。
- 从 1.0.0 之前的测试签名版本升级：签名不同，必须先导出外部 JSON 备份，再卸载旧版、安装 1.0.1 并恢复课表；账号密码需要重新保存。
- Windows 安装程序尚无 Authenticode 公共代码签名，系统可能提示未知发布者。
- 通用网页导入仍依赖页面中可识别的 HTML 课表结构，不保证所有高校、自绘页面、图片课表或跨域框架均能自动解析。
