# 课织 1.0.2

1.0.2 为设置页补充清晰、可信的官方更新渠道，支持 Android 7.0+（ARM64）及 Windows 10/11（x64）。

## 更新内容

- 设置页顶部的开发者卡片新增“官方更新发布地址”，明确 GitHub Releases 是课织安装包与版本说明的更新推送地。
- 显示完整地址 `https://github.com/flame-ray/kezhi/releases`，支持一键复制。
- Windows 与 Android 原生版可点击“打开更新页”，通过系统默认浏览器进入 GitHub Releases。
- 浏览器无法打开时自动尝试复制网址，并给出明确状态提示。
- 使用 Tauri 官方 Opener 能力，原生权限仅允许打开上述固定地址，不向前端开放任意外部网址。
- 保留 1.0.1 的空白教务网址、通用初始校历及醒目的开发者联系方式布局。

## 验证情况

- 152 项前端单元测试、18 项 Rust 测试通过。
- 手机尺寸界面检查通过：验证更新地址处于设置页顶部、网址显示完整、打开按钮调用受限原生接口、复制网址正确，后续调课记录与导入备份流程不受影响。
- Android 生产 APK 使用与 1.0.0／1.0.1 相同的正式证书签名，并检查版本信息、v2/v3 签名、16 KiB 对齐和内置前端资源。
- 本轮仍未完成全部手机系统默认浏览器及网络环境的真机验收；无法访问 GitHub 时可复制网址后在可用网络环境中打开。

## 升级说明

- 1.0.0／1.0.1 正式版用户可以直接覆盖安装，应用本地数据会保留；升级前仍建议导出 JSON 备份。
- 1.0.0 之前的测试签名版本不能直接覆盖，须先导出外部 JSON 备份，再卸载旧版、安装新版并恢复课表；账号密码需要重新保存。
- Windows 安装程序尚无 Authenticode 公共代码签名，系统可能提示未知发布者。
