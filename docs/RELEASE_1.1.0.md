# 课织 1.1.0：考试中心与应用内检查更新

本地测试阶段记录；这些功能已合并到 1.1.1 一起发布，公开发行以 GitHub Releases 为准。

## 考试中心

- 从“今天 → 考试中心”或“设置 → 考试中心”进入，保留五个底部导航按钮。
- 添加、编辑考试名称、实际日期、起止时间、考场、座位号及备注。
- 支持待考试、已结束、全部筛选与搜索；显示倒计时、考试中和已结束状态。
- 考试时间相互重叠时提示确认；删除需确认，并可撤销最近一次删除（离开应用前）。
- “今天”按考试实际日期显示，即使在当前学期之外也不隐藏。调整开学日、年级或课表周次不改变考试日期。
- 每场考试可选择提前 1 天、60/30/15 分钟提醒。须在设置开启系统课程与考试通知，并授予系统权限。
- 课程与考试按提醒时间合并，最多预定未来 128 条；启动或修改相关数据时补充安排。系统省电、权限和设备状态可能影响实际送达，不承诺强制准时唤醒。
- SQLite schema 升级至 9，保留已有课表、成绩、选课配置。JSON 全量备份包含考试；恢复没有考试字段的旧备份会保留本机考试；恢复“导入前课表”不更改考试。

## 应用内检查更新

- 设置页可手动检查 GitHub 上的最新正式版本，显示当前/公开版本、更新说明及安装包大小。
- 版本号按数字比较；不将草稿、预发布版或错误来源视为正式更新。
- 网络超时、GitHub 限流与格式异常会提示重试；关闭弹窗不影响本地数据。
- 原生版通过固定 HTTPS 地址查询公开 Release 元数据；不传入学校网址、账号、密码或课表。
- “前往下载页”使用现有官方更新地址。当前不包含应用内下载进度、静默安装或强制更新。
- 开发者联系方式继续放在设置顶部，GitHub 是官方更新发布地。

## 本轮边界

考试目前手动录入，尚未接入教务考试抓取或考试 ICS 导入/导出；现有课表日历导入不受影响。没有修改自动选课/自动提交逻辑。新界面沿用现有弹窗和页面过渡，支持深浅色与减少动态效果设置。

Android 继续使用既有正式签名（versionCode 10100），不生成新密钥。Windows 安装包仍未提供公开 Authenticode 签名。

## 本地验证（2026-09-12）

- 前端单元测试：166 项通过；Rust 测试：21 项通过，包含 schema 8 → 9 迁移和非法考试写入不覆盖旧数据。
- 界面回归：考试/更新 5 组、维护入口 4 组、手势/日历 11 组、动效 9 组、学校登录/解析 7 组通过。界面网络使用模拟响应，不执行真实选课提交。
- 浏览器动效抽样 P95 约 16.8 ms，未观察到长任务；该值不能代替手机实测帧率。
- 前端生产构建、Android arm64 Release 与 Windows NSIS 构建通过。Android 使用原正式证书签名并通过 v2/v3 校验。
- 当前没有 ADB 真机连接；通知实际送达、系统侧滑返回及真机性能仍需安装验证。尚未推送或发布 GitHub。
