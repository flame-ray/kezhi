# 课织 1.1.1：双返回桌面与考试日历

包含此前 1.1.0 本地测试版的考试中心、考试提醒、备份及应用内检查更新；这些功能一并公开发布。

## Android 首页双返回

- 没有弹窗、课程详情或添加课程草稿时，在课表首页返回一次，显示“再返回一次回到桌面（2 秒内）”。
- 2 秒内再次返回才打开桌面，应用不主动结束进程或清除课表数据。
- 超时、点击其他操作、切到后台后重新计时，避免之前的返回操作导致误退出。
- 编辑课程、考试、导入、设置等弹窗优先关闭；“今天”、成绩、选课等页面继续返回上一级。Windows 行为不变。
- 系统不允许打开桌面时提供错误提示，仍留在应用内。

## 考试 ICS 导入与导出

- 考试中心增加“导入考试 ICS”，先读取预览、勾选，再明确导入；不覆盖本机已有考试，不改动课表。
- 文件中无效事件逐条说明跳过原因；支持单次考试、UTC、北京时间及无时区的本地时间，最终按设备时区显示。
- 暂不支持全天、跨天、重复及例外事件、缺失结束时间、非整分钟时间或其他时区；不会自行猜测日期与时长。
- 重复标识和相同考试不重复添加；与已有考试时间重叠时需确认。
- “导出所列 N 场”导出当前筛选/搜索结果。ICS 含日期、考场、备注、座位号与已配置的提醒。
- Android 使用系统文件保存窗口选择位置，无需申请全部文件访问权限；取消保存不显示成功。保存后可用支持 ICS 的日历软件打开。
- 课织自己的 ICS 可保留座位号、备注及提醒设置；其他来源的提醒不会自动启用，可导入后自行设置。
- 单个文件上限 4 MB，最多解析 1000 个事件。

## 保持不变

默认教务网址仍为空；开发者联系方式仍在设置顶部；自动选课/自动提交逻辑、五个底部导航按钮与课表原有操作不变。Android 继续使用既有正式发行签名（versionCode 10101），Windows 仍未配置公开 Authenticode 签名。

## 验证与限制

181 项前端测试通过，覆盖双返回超时/重置、日历格式、时区转换、重复导入与导出回读；21 项 Rust 测试通过。界面测试使用模拟 Android 通信检查首页双返回、弹窗层级、导入确认和导出取消，不执行真实选课请求。Android arm64 Release 构建通过。当前没有连接 ADB 真机，真实桌面切换、文件选择器以及系统通知仍需安装验证。
