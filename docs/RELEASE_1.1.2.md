# 课织 1.1.2：考试复习清单（本地待发布）

## 快速录入考试

- 新建考试时，可从已有课表选择课程名称；重复课程合并成一个选项，空课表不显示选择器。
- 只带入名称，不猜测考试日期、时间或考场；这些信息仍由用户按照考试通知填写。
- 保存后的考试独立于课表，修改课程不会联动改变考试。

## 复习清单

- 每场考试可添加最多 30 项复习任务，每项最多 100 个字符，支持改名、完成勾选、删除和撤销最近一次删除。
- 编辑器及考试卡片显示完成数量与进度。输入新任务后直接保存考试，也会保存尚未点击“添加任务”的内容。
- 修改在点击“保存考试”后生效，取消编辑保留之前的数据；错误提示自动滚入可见区域。
- 清单保存在本机，随 JSON 备份保留；普通 ICS 日历导出不携带私人复习清单。旧考试与旧备份仍可读取。
- 前端和本地数据库均校验清单数量、标题、标识与完成状态；无效数据不会覆盖已有记录。

## 兼容与边界

- 复用已有考试编辑弹窗和返回层级，未改动自动选课/提交、教务登录、默认网址及首页双返回行为。
- 进度条仅做变换动画，遵循系统减少动态效果设置；任务没有单独的到期时间或通知。
- Android versionCode 10102，沿用既有正式签名；Windows 不含公开 Authenticode 签名。
- 188 项前端测试、22 项 Rust 测试通过；新增界面回归覆盖快速录入、增删改勾选、撤销、保存、取消、小屏幕和减少动态效果。原有双返回与考试日历流程一并回归。
- 尚未在连接的 Android 真机上验证，本地构建不代表已发布到 GitHub。
