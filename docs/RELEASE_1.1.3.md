# 课织 1.1.3：待复习筛选与快速填写（本地待发布）

## 考试中心

- 新增“待复习”筛选：只显示尚未结束且存在未完成复习任务的考试。支持与名称、考场、备注搜索组合使用，并按考试时间排序。
- 清单完成并保存后，该考试从“待复习”筛选中移出，原考试仍在“待考试”或“全部”中，不会删除任何数据。空清单不视作已准备好，也不计入待复习结果。
- 空结果有明确说明；日历导出继续只导出所列考试，结果为空时禁用。
- 手机考试页面收紧顶部留白，将搜索与筛选并排，给课程卡片和复习进度留出更多空间。
- 快速填写增加成绩来源，按“来自课表”“来自成绩（含历史学期）”分组，跨来源同名课程优先显示在课表组，重复名称仅保留一个选项。
- 只填入名称，不带入成绩、时间、教室或考场，不自动创建补考；选取后可继续手动编辑，保存前不会写入考试。
- 已存在时间重叠的考试，仅修改清单、备注等非时间信息不再重复要求冲突确认；新建或修改日期、起止时间仍需确认冲突。

## 数据与兼容

- 复习清单的本机存储、JSON 备份、导入前课表恢复逻辑不变。新增测试验证重复 ICS 导入不覆盖原清单和进度，损坏的清单备份被明确拒绝。
- 普通 ICS 不附带私人复习清单；课程导入、自动选课/提交、账号密码和返回导航逻辑未修改。
- Android versionCode 10103，沿用既有正式发行签名；Windows 尚未提供 Authenticode 签名。
- 前端测试 195 项、Rust 测试 22 项通过。界面回归覆盖历史成绩快速填写、去重、空课表、待复习搜索、完成后更新、时间冲突、取消及重载；原有双返回、考试日历及检查更新一并通过回归。
- 本地构建不代表 GitHub 已发布；无连接真机，实机触控、系统通知仍需安装验证。
