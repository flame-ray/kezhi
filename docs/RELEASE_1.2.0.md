# 课织 1.2.0：校园位置与示意路线（本地待发布）

## 使用方式

1. 在“课表”或“今天”点选课程，再点教室所在的整行按钮。
2. 地图自动定位并高亮识别到的楼栋；不选起点也能查看。
3. 在地图上点自己的位置，或从“我的位置”选择所在楼栋，自动显示示意步行路线。
4. 支持放大、缩小、全图、回到目标、重新选起点和清除路线。地图滚动和点选区分处理；多指、取消或拖动不设起点。
5. 系统返回、Escape 或“返回课程”只关闭地图，保留课程详情。起点随地图关闭清除，不写入课表或备份。

## 教室识别规则（用户提供）

| 房号首字母 | 楼栋 |
| --- | --- |
| A | 求知楼 |
| B | 求真楼 |
| C | 求实楼 |
| D | 求是楼 |

忽略第二个字母，兼容大小写、全角字符、空格及常见连字符，例如 `cc301`、`C-C401`、`B-B301`。讲堂群及其他已收录地点按名称识别，较长的具体楼名优先于“实验楼”等通用名称。多个楼名、未知编码、纯数字教室不会猜测，允许手动选楼栋。

## 数据与隐私

- 底图、楼栋框及道路图均随应用打包，地图功能无需联网，不调用浏览器 GPS，也不新增 Android 定位权限。
- 按道路节点和连接线计算最短图路径；地图点选吸附到附近道路，远离路网或湖内的位置不规划路线。点楼栋时以附近道路节点作为起点。
- 楼栋范围和道路基于 AI 重绘示意图手工标注，不含实测坐标、真实距离、时间、楼层或无障碍通行数据。不可视为经实地验证的导航。校内道路、入口及开放状态需进一步核对。
- 南大门按原图“在建”处理，只允许高亮，不作为起点或终点规划路线。
- 仅适用这张图对应的校区；不是其他学校的通用房号规则。未修改自动选课、账号密码、教务接口或系统更新配置。

## 验证

- 221 项前端测试通过，包含 26 项地图匹配与路由用例；覆盖所有开放地点间的图连通、湖内点选拒绝、未知地点和楼栋规则。
- 22 项 Rust 单元测试通过；前后端共 243 项单元测试通过。
- 界面回归覆盖课程入口、仅高亮、道路/楼栋起点、清除、多次打开、拖动防误触、未知楼栋手选、移动端/桌面端及 Android 返回层级；测试拦截确认未发出 GPS 请求。
- 当前无连接真机，尚未验证实机触控表现或实地道路。Android versionCode 10200，沿用既有正式发行签名；Windows 未配置 Authenticode 签名。
