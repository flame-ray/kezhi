# 课织 1.2.1：当前教学周与滑动优化（本地待发布）

- 启动时按本机日期和已保存校历打开对应教学周，不再固定第 1 周。兼容 SQLite 异步加载、JSON/日历导入和恢复备份；不改变用户的开学日期或课程周次。
- 今天日期显示“今天”与主题色底，日期整列增加淡色背景；亮暗主题均生效，非当前周不误高亮。
- 跨日及后台恢复时重新检查日期。当天手动浏览其他周不会被普通课程编辑或同日窗口聚焦打断，“本周”仍可随时返回。
- 翻周采用显式 transform 合成层动画，移除松手阶段强制布局；动画结束与三页重置同帧提交，避免旧页闪回。拖动按帧合并，结束速度与剩余距离参与时长计算；停住再松手不保留陈旧甩动速度。
- 保留取消手势回弹、长按防误触、原有课程拖动及系统减少动态效果设置；不修改账号、选课或地图功能。
- 开学前显示第 1 周，超过支持范围显示第 30 周；今天不在所示周时不强行高亮其他日期。
