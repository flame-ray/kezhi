# 1.4.0 — 小组件个性化与课程直达（本地待验收）

归档说明：1.4.0 的功能与后续设置修复合并为 [1.4.1](RELEASE_1.4.1.md) 发布，不单独建立与当前源码不对应的旧版本标签。以下保留当时的本地构建记录。

本轮只生成 Android arm64 安装包，未推送 GitHub / 创建 Release。Windows 安装版不更新；教务登录、选课、成绩等流程保持原样。

## 已实现

- 每个桌面小组件单独保存：跟随系统／浅色／深色，背景不透明度 100%／75%／50%，字号 90%／100%／115%，舒适／紧凑排版。密度作用于全天课程行。
- 设置 → 小组件外观设置，可选择已有小组件并预览实际课程（最多两堂）。保存才应用，取消不会保存。也可以点全天面板标题进入当前组件设置，或使用支持重新配置的桌面入口。
- 实色跟随系统时保留系统配色，半透明使用对应明暗的中性底色；文字不随背景一起变透明。
- 全天面板底部今天／明天按钮，每个小组件独立切换，跨过本地午夜后默认回到今天。不抢占桌面的横向滑动手势。
- 点下一节卡片或全天列表中的课程，打开应用内对应课程详情，再使用已有教室地图、提醒、编辑／单次调课入口。
- 跳转按课程实例 ID 和日期匹配。原生校验缓存，前端在本地课表加载后再次校验；被删除、取消或移动的旧目标提示已变更，不猜测同名课程。冷启动与已打开应用均支持。
- 使用读取后确认的待处理跳转，避免 React StrictMode 或加载时序丢失事件。编辑课程／成绩／考试、导入或单次调课期间暂缓处理，不丢弃正在编辑的内容。
- 外观设置页显示课程数据实际同步时间，未同步时明确提示，不把调整样式或刷新视图当成新数据同步。

## 兼容与验收

沿用 1.3.2 的尺寸回调重排与全天连续列表；空间不足时滚动，不隐藏已结束课程，不截掉后续课程。新数据仅增加本地课程实例 ID，不含学号、账号密码或成绩。旧缓存仍可读取；升级后先打开课织完成一次同步，课程点击直达才有完整的实例信息。

原生设置 Activity 采用系统返回行为：返回／取消不保存，保存更新当前小组件。小组件配置数据在应用私有存储中，删除组件时清理其设置。

已覆盖前端课程匹配与 UI 冷／热启动、过期目标拒绝、外观设置桥接、原生独立设置／跨日重置／点击目标／配置预览不保存／Android 9 样式兼容。截图在 Android app 的 `build/reports/widget-previews-1.4.0/`，使用测试数据。

目前未连接真机，仍需在小米桌面验收：多个小组件独立配置、缩放和旋转后的外观、明天列表滚动、课程点击冷启动、首次添加／重新配置流程、系统返回手势。桌面拉伸动画与后台刷新仍受系统限制。
