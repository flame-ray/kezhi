# 1.4.1 — 小组件个性化、课程直达与外观设置修复

合并 1.4.0 的小组件主题、透明度、字号、密度、今天／明天及课程详情跳转，并修复外观设置可靠性问题。源码和 Android arm64 安装包统一按 1.4.1 发布；Windows 安装版与教务／选课流程不变。

## 改进

- 新增“恢复默认外观”：只改变当前预览，保存后才应用；取消仍保留原设置。
- 旋转屏幕或系统重建设置页后，恢复已选择的小组件和未保存的外观草稿。
- 在应用设置入口切换多个小组件，各自暂存本次页面内的选择，不再切一次就丢失；保存只应用当前组件。
- 从桌面添加或重新配置指定组件时，只配置该组件。目标已被删除时提示重新添加，不会偷偷改成另一个组件。
- 预览宽度变化后重新布局，避免初次布局尚未完成或旋转后预览不更新。

草稿只随当前页面及其系统重建状态保留，并非永久自动保存。关闭／取消后不会写入外观偏好；需要生效的设置应点击保存。

## 验收

新增回归测试覆盖旋转恢复、多个草稿独立保留、指定组件锁定、目标失效以及恢复默认后取消。

前端 230 项测试和 Android 原生 38 项测试通过。发布前重新验证小组件冷／热启动跳转、过期目标提示、同步失败重试及平台入口。

构建流程在 GitHub Actions 中生成未签名 APK，再由开发者本机使用原正式密钥签名；不向 GitHub 上传密钥或密码。工作流仅手动触发，不自动发布未签名安装包。
