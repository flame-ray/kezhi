# 1.4.2 — 小组件同步诊断与手动修复

## 新功能

- 设置中新增“小组件同步状态”，查看已添加组件数、今天课程次数、最近课程同步时间和课程日期范围。
- 明确区分未同步、空课表、缓存无法读取、尚未添加组件、课程尚未开始、课程日期已结束及今天无课，并给出对应操作建议。
- 新增“立即刷新”：重新写入当前课表并请求桌面刷新，即使课程内容没有变化也执行。不修改课程、周次、调课记录或组件外观。
- “重新检查”只读取状态，不改写同步时间。返回设置页时重新检查，无后台轮询。
- 状态读取与刷新失败均可重试；缓存状态不等于桌面已完成显示，明确保留系统省电／桌面延迟提示。

## 数据与验证

诊断接口只返回数量、日期和时间戳，不返回课程名、教室、课程 ID、账号或密码，不连接教务系统。课程同步仍然只有本机缓存。

新增前端状态校验／提示测试、Android 原生元数据测试及界面端强制刷新／失败重试测试。真实小米桌面的省电与刷新表现仍需真机验收。

同时升级开发测试工具 Vitest 至 4.1.11 并更新 source-map-js，消除本轮依赖审计发现的告警；不更改选课逻辑。参考 [Vitest 安全修复说明](https://github.com/vitest-dev/vitest/security/advisories/GHSA-82fw-gwwq-j7x9)。依赖审计通过不代表应用不存在其他安全问题。

本轮仅更新 Android 安装包，Windows 仍使用此前 v1.3.0。构建使用手动触发的 GitHub Actions，签名继续在本机使用原正式密钥完成。
