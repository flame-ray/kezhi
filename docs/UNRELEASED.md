# 待发布：课表显示与网页导入修复

本文件记录 v0.4.5 之后的主分支改动；未修改已有 Release 或标签。版本号仍为 0.4.5，本地测试 APK 不是新的正式发行版本。

## 课表交互

- 长按空白格先选中时间范围，使用上下箭头调整起止节次，再点加号打开编辑；原长按抬手不再误触确认。
- 非本周课程半透明显示。正式上课日在周中时，第 1 周此前日期的课程保留展示，并标记未开课；实际日程、提醒和日历仍遵循上课日期。
- 同一天重叠的课程合为一个入口，优先展示本周课程，点击可查看全部课程；避免多张半透明卡片叠字。课程数据不删除。

## 学校登录和导入

- 新学校不必先填写本地学号即可打开登录网页；保存密码时仍需填写对应账号。
- 账号保存失败会在界面显示，并允许重试；较长学校域名生成的标识符合原生长度限制。
- Android 通用课表模式对新的标准 HTTPS 认证域名逐个请求用户确认，不自动放行任意站点，不向新域名填充已保存密码。
- 通用模式由用户点击“导入当前课表”，不再用宁德师院的 Cookie 特征判断其他学校；显示加载失败、证书失败和未找到表格的提示。
- 课表按钮移至底部独立操作栏，最小高度 56dp，保留系统手势区、刘海和键盘空间；不会覆盖网页。顶部选课学习按钮及原自动选课流程保留。
- 网页课表采集在本机进行，保留换行和合并单元格信息，支持同源框架；不采集表单输入值，并跳过显示密码输入框的页面。
- 表格解析支持多行表头、合并节次，避免把上课时钟误作节次。

## 已验证

- 115 项前端单元测试、16 项 Rust 单元测试通过。
- 4 项通用登录/真实 DOM 采集浏览器检查、4 项课表范围与重影检查、10 项手势/日历检查通过。
- 前端生产构建、Android Rust/Kotlin 编译、APK v2/v3 测试签名校验通过。
- 浏览器用例使用本地测试页面和模拟原生调用，未登录真实学生账号。底部原生布局尚待不同品牌手机实测。

## 仍有限制

- 不代表所有高校已完成适配。通用解析主要支持 HTML 课表矩阵，不保证自绘页面、图片课表、跨域框架和所有统一认证流程可用。
- HTTP 老系统不支持；通用 Android 跨域认证确认目前限定标准 HTTPS 端口。Windows 通用网页登录仍受同域导航限制。
- 缺少明确周次的网页记录仍有默认周次推断，导入前应仔细核对，后续需改为显式补充确认。
- 正式发行签名、真机多厂商验收和更多学校端到端测试仍待完成。
