# 待发布：单次调课、课表显示与网页导入修复

以下为 0.4.5 之后的历史开发记录；当前 1.0.0 的功能和限制以 [1.0.0 更新说明](RELEASE_1.0.0.md) 为准。

本文件记录 v0.4.5 之后的工作版本改动，不代表全部已经推送；未修改已有 Release 或标签。版本号仍为 0.4.5，本地测试 APK 不是新的正式发行版本。

## 课表交互

- 长按空白格先选中时间范围，使用上下箭头调整起止节次，再点加号打开编辑；原长按抬手不再误触确认。
- 非本周课程半透明显示。正式上课日在周中时，第 1 周此前日期的课程保留展示，并标记未开课；实际日程、提醒和日历仍遵循上课日期。
- 同一天重叠的课程合为一个入口，优先展示本周课程，点击可查看全部课程；避免多张半透明卡片叠字。课程数据不删除。

## 学校登录和导入

- 新学校不必先填写本地学号即可打开登录网页；保存密码时仍需填写对应账号。
- 账号保存失败会在界面显示，并允许重试；较长学校域名生成的标识符合原生长度限制。
- Android 通用课表模式对新的标准 HTTPS 认证域名逐个请求用户确认，不自动放行任意站点，不向新域名填充已保存密码。
- 通用模式由用户点击“导入当前课表”，不再用宁德师院的 Cookie 特征判断其他学校；显示加载失败、证书失败和未找到表格的提示。
- 课表按钮移至底部独立操作栏，最小高度 56dp，保留系统手势区、刘海和键盘空间；不会覆盖网页。顶部选课学习按钮及原自动选课流程保留。
- 网页课表采集在本机进行，保留换行和合并单元格信息，支持同源框架；不采集表单输入值，并跳过显示密码输入框的页面。
- 表格解析支持多行表头、合并节次，避免把上课时钟误作节次。
- 缺失、格式错误或只有单双周标注的周次进入逐条确认，不再默认补为 1–20 周。允许输入 1–30 周内的范围/列表或明确跳过；保留已知单双周条件，并显示网页原文和最终课程预览。
- 有待确认记录时禁止导入；全部跳过、没有有效课程时也不能用空课表覆盖已有数据。旧版本已经导入的记录不会自动改写，需用户重新导入核对。
- Android 课表浏览器底部增加返回、前进、刷新/停止/失败重试和网址编辑，上方显示加载进度。网址编辑继续受原有 HTTPS/域名确认限制；刷新需要重发表单时先确认，证书失败不绕过。

- 7 项通用登录/周次确认/真实 DOM 采集浏览器检查通过，含阻止不完整周次、保留单双周、明确跳过和空替换拦截；亮暗主题截图已检查。此前的 4 项课表范围与重影检查、10 项手势/日历检查通过。

- 浏览器用例使用本地测试页面和模拟原生调用，未登录真实学生账号。底部原生布局尚待不同品牌手机实测。

## 仍有限制

- 不代表所有高校已完成适配。通用解析主要支持 HTML 课表矩阵，不保证自绘页面、图片课表、跨域框架和所有统一认证流程可用。
- HTTP 老系统不支持；通用 Android 跨域认证确认目前限定标准 HTTPS 端口。Windows 通用网页登录仍受同域导航限制。
- 缺少明确节次或不能识别的非矩阵网页仍需进一步适配；本轮不提供图片 OCR 或未知学校接口自动适配。
- 浏览器工具栏为 Android 端新增能力；前端模拟测试不代表已完成真机网络失败、输入法和每所学校的登录验收。
- 正式发行签名、真机多厂商验收和更多学校端到端测试仍待完成。

## 单次调课／停课（2026-09-10）

- 点课程详情的“仅这一次调课／停课”，可只修改所选日期的上课日、节次和教室，或停掉这一节；其他周保留原始课表。
- 原日期显示淡色停课／调走标记，新日期显示调课后的课程；点击任一记录可修改或撤销。支持从“今天”的所选日期进入，不误用周课表当前周。
- 变更单独保存在本地 SQLite，重启后保留；JSON 备份同时保存原课程和变更。旧数据库自动补充字段，不删除原数据。
- 周课表、今天、课程提醒、ICS、CSV、SVG 和手机日历导出使用相同的单次变更结果。取消的课程不计入今天上课数量、不产生提醒或导出事件。
- 调课后的日历事件保留原事件标识；更换学校账号或学期导入时清除旧上下文的单次记录，日历替换导入及删除课程也会清理对应记录。
- 弹窗使用现有底部面板动画，亮暗主题及小屏底部按钮可达性已检查；系统返回处理优先关闭这一层。
- 本轮不修改自动选课执行代码，不向教务系统提交任何调课操作。

限制：已导入手机日历的停课事件不会自动删除，需要手动清理；调课后需要重新导入。改动原课程或学期基准日期后，与新课表不匹配的记录不再应用。尚未实现学校官方调课同步。

### 调课时间冲突确认

- 根据目标日期、节次和已有单次调课／停课记录，列出真正重叠的课程，忽略非本周和已停课课程。
- 同一门课另一周的安排也参与检查；编辑原地教室或已有变更时，不把正在编辑的这一节当成自身冲突。
- 出现冲突后须勾选明确确认才能保存；更改日期、节次、教室或操作类型后重新确认。不删除、不移动冲突课程。
